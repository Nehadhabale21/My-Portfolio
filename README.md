# My Portfolio

Welcome to my personal portfolio! This website showcases my skills, projects, education, certificates, and ways to contact me. It is built using modern web technologies with a focus on clean, functional design.

---

## 🌐 Live Demo

[View Live Portfolio](https://nehadhabale21.github.io/My-Portfolio/)  


---

## 📌 About This Project

This is a responsive, single-page portfolio website designed to:

- Introduce myself as a **Java Developer**
- Showcase my **projects** and **skills**
- Highlight my **certifications** and **education**
- Provide a **contact form** to connect with me

The portfolio uses a modern gradient-based theme with glowing effects for visual appeal.

---

## 🛠 Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** CSS Flexbox, Grid, Gradients, Animations
- **Features:**
  - Fully responsive design
  - Smooth scroll navigation
  - Glowing hover effects for skills and projects
  - Circular image halo animations
  - Contact form using `mailto`
